# Reguli pentru acest repository

## Logo SISTEMICA MOTION (brand, nu se modifică)

Logo-ul este brand. Regula permanentă: în logo, punctul roșu (#B1202B) din „MOTION” rămâne mereu aliniat cu litera A din „SISTEMICA”. Nu modifica această aliniere niciodată, nici în header, nici în footer, nici la alte dimensiuni.

În header, „MOTION” rămâne aliniat la dreapta, iar „MOTION” este înclinat (italic), pentru că înclinarea simbolizează mișcarea perdelei.

În footer, logo-ul are aceeași culoare închisă ca în header (#211E1B), fără bold și fără subliniere, pe fundalul footerului identic cu al headerului (#D9CEBF). Aliniamentul este identic cu cel din header: „MOTION” aliniat la dreapta, sub „SISTEMICA”, cu punctul de accent sub litera A. Dimensiunea footerului este cu 30% mai mică decât logo-ul din header.

Descrierea „distribuitor exclusiv TOSO Japonia în România” stă pe un singur rând pe desktop și trece pe rând nou doar pe ecrane înguste.

## Footer

Datele firmei folosesc același font și aceeași dimensiune pentru etichete și valori. Între etichetă și valoare trebuie să existe spațiu.

Anul din copyright este generat din JavaScript (`.foot-year`), cu anul curent al vizitatorului. Valoarea 2026 din HTML este doar rezervă, dacă JavaScript este dezactivat.

## Fundaluri

Footerul are fundalul headerului (#D9CEBF). Secțiunile dintre header și footer alternează #FAF9F5 și #EAE6DB, fără olive; două blocuri vecine (inclusiv header și footer) nu au niciodată aceeași culoare de fundal. Textele trebuie să contrasteze lizibil cu fundalul.
